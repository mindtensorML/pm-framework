# Portfolio Construction Framework, version 3

Live map at https://mindtensorml.github.io/pm-framework/

This is a general portfolio construction process in 7 steps and 35 sub-steps, running from defining the purpose and rules to construction, execution and monitoring. A decision node routes each portfolio by objective type (5 routes), and another routes by selection method. Three feedback tiers send problems back to the right step.

Built by Caesar Rana, CFA, at SpaceXAI and shared with permission. The map describes a general method and contains no client data. See all the maps at https://mindtensorml.github.io/
